# Changelog

## [1.1.0] - 2026-11-26

### Added
- Support for stacking piles upward by aiming at the top of a full 64-stick pile to start a new stack above it.

## [1.0.0] - 2026-11-25

### Added
- Initial release.
- Stack up to **64 sticks** per block in **8 layers of 8 sticks** using standard ground-storage controls.
